# 欧陆改革宗 · 使徒信经研读

静态 HTML 教学站：以**三项联合信条**（比利时信条、海德堡要理问答、多特信经）与**尼西亚信经、亚他那修信经**为坐标，先宏观（救赎历史、圣经神学、圣约、三一）后逐条讲解使徒信经。

使徒信经传统中文全文收录于页面。其他信经与信条只标条款 / 问答号，不转载全文。

## 特色

- 深色海军 / 金色玻璃主题，全文宽栏阅读
- **body 级可隐藏目录**（手机抽屉，高层级，不与正文重叠）
- 重点 / 难点等色标、对照表、记忆十六钉
- Mermaid 流程图（标签用 `<br/>`，不用思维导图交叉线）；故事线为 HTML 卡片
- 每条包含：说什么、前因后果、多角度、信条坐标、记忆与应用
